# 🚀 一步 StepOne — AI 求职成长陪伴工具

> 一款面向在校大学生的 AI 求职成长陪伴产品，帮你从迷茫到上岸。

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🎯 **个人定位** | 6 步引导问卷，建立专业、学历、阶段三维画像 |
| 💬 **AI 对话** | 流式对话，整理经历、挖掘亮点、个性化建议 |
| 🧭 **职业测试** | 12 题霍兰德测评，六维雷达图 + 类型解读 + 岗位推荐 |
| 📊 **能力雷达** | 基于对话动态生成多维度能力画像 |
| 🗺️ **发展路径** | AI 定制从基础到冲刺的完整成长路线 |
| 🏔️ **里程碑** | 自定义成长目标，卡片式追踪进度 |
| 📖 **叙事重构** | 经历 → STAR 法则拆解，故事挖掘 |
| 📄 **简历优化** | AI 用 STAR 法则重写简历 |
| 🎙️ **面试准备** | 针对目标岗位生成个性化面试准备包 |
| 🧘 **喘口气** | 求职焦虑树洞，AI 温暖回应 |
| 👥 **一步圈** | 校友网络 + 校招动态 + 匿名问答 |
